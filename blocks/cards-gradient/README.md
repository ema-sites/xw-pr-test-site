# cards-gradient

Custom **cards** block. Purpose: Grid of dark gradient cards for products/tours or captioned image demos.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 image; cell 2 rich text (title paragraph, CTA link paragraph, description paragraph) or a single caption line.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
