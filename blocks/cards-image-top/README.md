# cards-image-top

Custom **cards** block. Purpose: Row of borderless cards with image on top, title, body and link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 image; cell 2 rich text (bold title paragraph, body paragraph, link paragraph).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
