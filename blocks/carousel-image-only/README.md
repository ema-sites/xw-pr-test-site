# carousel-image-only

Custom **carousel** block. Purpose: Rotating full-width image showcase without text.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: cell 1 image; optional cell 2 text (left empty on the source page).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
