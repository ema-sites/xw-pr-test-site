# columns-media

Custom **columns** block. Purpose: Stacked image/text rows at about 50/50.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per media pair: cell 1 image; cell 2 rich text (H2, paragraphs, optional lists).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
