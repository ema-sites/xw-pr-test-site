# columns-teaser

Custom **columns** block. Purpose: Text-only two-column teaser: display heading left, body copy and CTA right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 heading (may include emphasized accent word); cell 2 paragraph(s) + a link-only paragraph as CTA.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
