# hotspot

Custom **custom** block. Purpose: Interactive image map that launches media.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: row 1: background image; then one row per hotspot: cell 1 media link (video /play URL or Dynamic Media viewer URL), cell 2 left position %, cell 3 top position %.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
